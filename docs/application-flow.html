01 / 全体

声を聞いて、返事をして、また待つ。

会話の主な流れ。文字で送信した場合は、話し終わりの検出と宛先の判定を通らずに返答へ進みます。

100%

図は縦横にスクロールできます。↗ の箱を選ぶと詳細の図へ移動します。

起動時の準備

マイク許可、会話モデル、記憶、声と聞き取りの準備を確認。初回は「はじめる」から開始します。準備に失敗したときは、マイク許可と読み上げの準備の失敗を除き、短い定型文を声で案内してから理由を表示します。

話し終わりの検出

Smart Turnで音声から終了を判定。確定した聞き取り結果の無音区切り（通常1.2秒）や、20秒の区切りも併用します。

返事中のマイク

発話をまとめたら聞き取りを止め、返答が終わると再開します。話している猫に声で割り込む経路はありません。

02 / 応答する条件

誰か1人でもこちらを向けば、宛先判定を省略。

「判定を省略」は、猫への発話かどうかの判定を省くこと。聞き取り、話し終わりの検出、返答の生成は行います。

条件返答・動作聞き返し停止・案内
100%
例をたどる

通常の発話を上から順に確認します。聞き返しへの返事待ちだけは、顔向きや30秒ルールより先に処理します。

図は縦横にスクロールできます。矢印のラベルを条件として読み進めてください。

「今の、ぼくに言った？」と聞き返した後確認待ちは15秒。次の発話は先にこちらで扱います。

こちら向き→有効でこちら向きの顔が1人以上なら、判定せず今の返事のまま返答をつくる
向いていない→元の発話と聞き返し、直近の会話を添えて、Claude Haikuで判定する
猫宛てと判定→今の返事のまま返答をつくる
それ以外と判定→周りの人への発話や手がかりのない話は捨て、確認待ちを15秒の期限まで残す。聞き返しは重ねない
判定に失敗→確認待ちを解除して聞き取りを止め、定型文を声で案内してから、理由と「もう一度」などの再開方法を表示する
返答の内容→文意が肯定なら元の話題に答え、否定なら短く受け止める。元の発話は送り直さない

顔向きの条件

カメラに何人映っていても、新しい映像に有効でこちら向きの顔が1人以上いれば省略します。瞳の目線までは判定しません。カメラ許可と新しい映像が必要です。

30秒ルール

返答完了後は顔や呼び名なしでも会話の続きとして扱います。返答ごとに30秒を延長しますが、同じ継続窓は最長5分です。顔向きなどで新たに受理すれば窓を作り直します。 複数人の中の顔向きを確認できた場合も、同じように窓を開始・更新します。

モデルによる宛先判定

判定はいつもClaude Haikuが行い、聞き取った発話と直近の会話（利用者と猫の往復、新しい側から最大4,000文字）をJSONで送ります。端末内モデルは使いません。確認待ち中にこちらを向かずに届いた返事は、元の発話と聞き返しも添えて判定します。判定が失敗したら定型文を声で案内してから理由を表示します。顔を検出できないだけで会話が止まるわけではありません。

03 / 返答と記憶

返答はいつもClaude。失敗したら、定型文を声で案内する。

返答の作成、必要な道具の利用、会話の記録、失敗したときの案内をまとめた流れです。端末内モデルへの切り替えはありません。

条件返答・動作聞き返し停止・案内
100%

図は縦横にスクロールできます。矢印のラベルを条件として読み進めてください。

失敗は先に声で案内

つながらない・生成の失敗・日次上限・拒否・長すぎる入力・聞き取りの失敗などは、種類ごとに決めた短い定型文を読み上げてから失敗を表示します。本文が途中まで出ていた後の生成失敗も同じで、会話は記録せず、回数も増やしません。読み上げ自体の失敗、マイク許可の拒否、取り消しは声で案内しません。返答の後の自動保存に失敗したときは、未保存と表示して再試行を案内し、会話は続きます。

案内中の操作

定型文の途中で一時停止・新しい会話・すべて削除・文字入力が来たら案内を止め、その失敗の表示は出しません。文字入力はそのまま返答へ進みます。

必要なときだけ道具を使う

「見て」など視覚情報が必要なら前面カメラの静止画を1枚取得。「覚えて」や今後必要な事実は長期メモへ。首や表情の動きも返答中に要求できます。

記憶は2種類

短期の会話履歴・要約と、名前や好みなどの長期メモを使います。長い履歴は必要に応じて要約し、表示・記憶用の原文を音声向けの表記に書き換えません。

新しい会話／すべて削除

「新しい会話」は短期の履歴をリセットし、長期メモを残します。「すべて削除」は両方が対象。削除失敗時は完了扱いにせず、再試行を案内します。

眠るまでの時間は設定できます。下図の5分・10分は初期値です。

話している最中は眠らない

返答生成中・読み上げ中・聞き返し中は眠りません。人の発話を処理中も、終わるまで入眠を待ちます。

眠った後はタップで起こす

設定を閉じたり、アプリへ戻ったりするだけでは起きません。音声で起きる経路もありません。

準備や処理が失敗したら

原因に応じて「もう一度」「設定を開く」「文字で話す」などを表示。マイクが使えなくても文字入力で送れますが、返答モデル・音声再生の準備は必要です。

05 / 顔と首

顔で会話を始める条件と、首を動かす条件は別。

顔向きによる宛先判定の省略は、首のハードが未接続でも使えます。

条件返答・動作聞き返し停止・案内
100%

図は縦横にスクロールできます。矢印のラベルを条件として読み進めてください。

顔向きによる応答は首と独立

宛先判定の省略は、首の追尾スイッチやBLE接続を条件にしません。一方、首の追尾にはハードの接続と追尾ONが必要です。

複数の顔があるとき

1人以上がこちら向きなら宛先判定を省略します。顔と発声者は対応付けないため、別の人の声にも応答する場合があります。首の追尾は、こちら向きの候補から中央に近い顔などの優先順で1つ選びます。

カメラ・熱・安全の制約

カメラ不許可でも会話は継続。高温時は撮影と首の自動動作を休止します。手動操作・停止・設定や校正が優先され、切断時は首を動かしません。

06 / 読み上げ

表示する原文を保ち、声に渡す表記だけを整える。

数値の読みは既存ライブラリを使います。音量0の表示は、返答や音声生成を止めるための分岐ではありません。

条件返答・動作聞き返し停止・案内
100%

図は縦横にスクロールできます。矢印のラベルを条件として読み進めてください。

数量・時刻・IDの例

1,500,000円 → 百五十万円。7:30 → 七時三十分。明示IDは各桁を別区間で読むため、9桁の実機例は合成約5.4秒・再生約17.4秒です。

音量が0なら

「音量が0です」を表示。音量を上げると消えます。iPhoneの消音モードでも再生する設定なので、消音モードによる警告や停止は入れません。

声に関する制限

表示・記憶は変えず、URLやコード等は保護します。読みの全てを網羅するものではなく、非常に長いIDは既存の音声長上限に達して失敗する場合があります。
