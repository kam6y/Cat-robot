# issue #25: エフォート設定

設定「会話」の「考える深さ」を「エフォート」に変更し、`low`、`medium`、`high`、`xhigh` をこの順で選べるようにする。

## 方針

- 既存の `ConversationEffort`、Picker、UserDefaults、`fixedEffort` の経路を拡張する。固定 SDK 0.2.3 は選択可能な3モデルすべてで4値を受け付ける。
- ユーザー追記により、lowは `low(推奨)`、Opusは `Claude Opus 5.5(推奨)` と表示する。その他のエフォートはAPIと同じ英字で表示する。issue中の `midium` は既存のAPI値 `medium` と解釈する。
- 保存キー `conversation.claude.effort`、既定の `low`、不正値を既定へ戻す処理を維持する。設定変更は次に作成するセッションに適用する。
- 設定の説明文とREADMEも新しい名称・選択肢に合わせる。

## 検討した方法

既存経路の拡張なら保存済み設定とセッション境界をそのまま使える。別の設定型やモデル別の選択肢は、全モデルが4値を受け付けるため不要。依存更新、`max` の追加、タイムアウトや出力トークン数の変更はこのissueに含めない。

## 検証

4値の保存・復元、SDKへの変換、全選択モデルとの互換性、進行中と次回セッションの設定を確認する。Xcodeプロジェクトを再生成し、生成契約とSimulatorテストを実行する。agmsgで8:2のClaudeと方針と最終差分をレビューする。
