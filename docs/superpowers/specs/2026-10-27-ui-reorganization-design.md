# 会話画面・最初の画面・設定の整理

日付: 2026-10-27。基点: `feature/look` / `9ee8dac`（居眠り機能をコミットした時点。設計書は `docs/superpowers/specs/2026-10-26-idle-sleeping-design.md`）。
状態: Claude Designのキャンバス「Cat Robot UI整理」の「整理案 v1」ページを、2026-10-27に利用者が採用した（「いいと思う。これで反映して」）。キャンバスは利用者のみ閲覧できるため、実装に必要な内容は本書にすべて書く。実装者の立場での読み合わせで出た3点（一時停止のチップの条件、居眠り機能との基点、首のチップの条件）は、Claudeの判断として本書に反映した。

## 目的と背景

機能を足し続けた結果、会話画面の上部に状態の文字が最大4つ並び、字幕の位置が状態ごとに変わり、設定は8つの欄が縦に続く1枚の長いフォームになった。顔追尾の設定は「ロボット」と「中立と回転方向」に分かれ、カメラ許可は2か所、送信データの説明は4か所に重複している。最初の画面は横向きアプリなのに縦スクロールが必要で、起動するたびに表示される。

今回の整理で、会話中は顔だけを見せ、知らせる必要があるときだけ小さく表示する。設定は横向きの画面幅を使って分類し直し、重複をなくす。新機能は追加しない。

## 利用者が決めたこと

コメントで指示された内容:

1. 会話画面に返事の字幕を表示しない。
2. 聞き取り中の文字（「聞き取り中…」と途中の認識結果）を表示しない。
3. 活動状態の文字（「話しています」「考えています」など）を表示しない。
4. 字幕のない通常表示では、顔を画面の85%の大きさにする（現状は約75%）。
5. 最初の画面は内容を整理し、縦スクロールなしで収める。表示するのは初回だけにする。
6. 設定まわりを1から整理し直す。

Claudeが提案し、利用者が案v1ごと採用した内容:

7. 上のバーは普段、右上の「…」だけにする。知らせる必要があるときだけ左上に小さなチップを出す。マイクの状態を常時表示しないことも利用者が了承した。
8. 「新しい会話を始めました」などの一言は、下部に数秒だけ出す。
9. 一時停止中は顔を少し暗くする。
10. 設定は左にカテゴリ、右に中身の2列にする。顔追尾に関する設定は「カメラと顔追尾」にまとめ、「中立と回転方向」の画面にはロボットへ保存する値だけを残す。送信データの説明は「このアプリについて」の1か所にまとめる。

## 変えないもの

- 採用済みの顔のデザイン（neutral-b / happy-b）、9表情、口の動き、まばたき、Reduce Motionの扱い。顔のタップで一時停止・再開する操作。
- 右上「…」メニューの項目（文字で話しかける／設定／新しい会話を始める）と、居眠り機能で待機中に一部を無効にする挙動。
- エラーカードと回復ボタン、記憶の保存・復元・削除のカード、文字入力欄の見た目と送信条件。
- 首の接続・動作・校正、顔追尾、look、居眠りの動作。今回は表示と配置だけを変える。
- 聞き返し（「今の、ぼくに言った？」）は既存どおり読み上げる。字幕を消しても音声で伝わる。
- 黒背景、前面カメラが左に来る横向き固定（既存の Info.plist の向き）、Dynamic Islandとホームインジケーターの回避、44pt以上の操作領域、Reduce Transparency、最大Dynamic Type、VoiceOverへの対応。
- 校正中の制約: 「停止」をいつでも押せる、設定の「完了」を無効にする、スワイプで閉じられない、未保存のまま戻るときに確認する。

**相互レビューによる訂正:** 当初の「両方向の横向き」は古い設計からの転記だった。`7aef684` で確定したカメラ左固定を保ち、向きの追加対応は本変更に含めない。

## 会話画面

基準の寸法は iPhone 横向き 852×393pt、safe area は左62・右40・下11pt（既存の描画fixtureと同じ）。safe areaの数値はfixtureのウィンドウの値なので、実装では実機のsafe areaに本書のオフセットを足す。

### 通常表示

- 背景は画面端まで純黒。
- 顔: 会話画面の幅・高さに対してそれぞれ85%の枠に、既存の `CatFaceView` を描く。枠はsafe areaの水平中央、画面の垂直中央に置く（852×393では約724×334pt）。85%は定数として1か所に持つ。
- 右上: 「…」メニューのボタンだけを置く（右safe area + 12pt、上4pt、44×44pt）。
- 上部の状態の文字（マイク・活動状態・首の接続・記憶の通知）、返事の字幕、聞き取り中の文字は表示しない。`AppRootView` の熱による顔追尾停止のオーバーレイも、下記のチップに置き換えて削除する。
- `ConversationViewState.caption` などの値は保存とVoiceOverのために残す。表示しないだけにする。

### 状態チップ（左上）

左safe area + 16pt、上10pt。高さ32pt、角丸カプセル、背景 `#1C1C1E`、14pt、アイコン + 文字。複数あるときは横に並べ、最大Dynamic Typeでは折り返す。表示する条件と文言:

| 条件 | 文言 | アイコン |
|---|---|---|
| 猫のタップや音声の割り込みで止まり、タップで再開するまで（下記） | 一時停止中・猫をタップで再開 | 斜線付きマイク |
| `isLooking` | 見ています | カメラ |
| 居眠り機能の待機中（`inactivity == .sleeping`） | 待機中・タップで起こす | 月 |
| 接続が切れてから再接続するまで（下記） | 首を再接続中 | 回転矢印（橙） |
| 顔追尾が熱で停止（`FaceTrackingStatus.pausedForHeat`） | 熱のため顔追尾を一時停止 | 温度計（橙） |

- 一時停止のチップ（Claudeの判断）: phase の `.paused` は、猫のタップ以外にも、非active・バックグラウンド・設定を開いている間・「新しい会話を始める」の途中・「すべて削除」の途中・居眠りの待機中にも使われる。チップは「猫のタップ・音声の割り込み・音声出力先の変更で止まり、タップで再開できる」ときに出す。音声の割り込み終了時には自動再開しない既存の動作に合わせ、再開操作を案内する。現行の `ConversationViewModel` は一時停止の理由を保持していない（`userStop` は首の停止理由として渡すだけ）ため、表示専用の `ConversationViewState.isAwaitingTapToResume` を追加する。猫のタップ・音声の割り込み・音声出力先の変更で止めたら true、音声の再開・非active・新しい会話・すべて削除・音声の失敗で false にし、文字での会話を挟んで一時停止に戻る場合は保持する。止まる・再開する動作そのものは変えない。待機中は一時停止と「見ています」のチップを出さない（首の再接続と熱のチップは、待機中も首の接続を保つので併記する）。記憶の状態が会話を止めている間（`blocksConversation`。猫のボタンが押せない）も一時停止のチップは出さない。
- 「見ています」は look の設計書が必須とする撮影前の表示を、字幕からチップへ移したもの。表示してから静止画を要求するまでの0.1秒と、表示を消す条件は look の設計どおりにする。
- 首のチップ（Claudeの判断）: 「接続していたのに切れて、再接続を試している」ときだけ出す。起動直後の接続（`.connecting` / `.preparing`）、利用者が「接続を切る」を押した後（`.suspended`）、未選択、接続中には出さない。`RobotLink` は切断後、2秒ごとの再試行で `.reconnecting(_)` と `.connecting` を行き来する（`RobotLink.swift` の `disconnectedState` と接続開始処理）。そのため同じ機器で一度 `.connected` を経たことを記録し、その後 `.reconnecting(_)` になったら表示を始める。起動時に保存済みの首が電源オフで初回接続のタイムアウトを繰り返しても表示しない。再試行中の `.connecting` / `.preparing` の間は表示を保ち、それ以外の状態になったら消す（`RobotReconnectIndicator`）。接続済みだった記録はバックグラウンド等を挟んでも保持し、未選択または機器変更で消す。接続先の機器が変わったら判定を初めからやり直し、別の機器へ手動で変えたときの初回接続には出さない。今の `RobotConnectionStatus` ではこれらを区別できないため、チップ専用の判定を `RobotLinkSnapshot` から作る。VoiceOverの読み上げ（`robotStatus.message`）は今のまま変えない。
- `.failed` のときはチップではなく既存のエラーカードで知らせる。listening・thinking・speaking などの通常状態にはチップを出さない。

### 一時停止中の顔

一時停止のチップを出している間だけ、顔の不透明度を0.5にする。待機中（sleeping）は表情自体が違うので暗くしない。

### お知らせ（下部）

`memoryNotice` を画面下部の中央にカプセル（背景 `#1C1C1E`、15pt、下から18pt）で表示する。表示時間は、既存の自動で消える処理（`ConversationViewModel` の memoryNotice の期限）をそのまま使う。

### 文字入力・エラー・記憶カード・大きい文字

既存の「内容を優先する配置」（`prioritizesContent`: 最大Dynamic Type、文字入力、エラー、記憶カード）は、字幕と聞き取り中の文字を除いて維持する。

- 文字入力: 入力欄を下部に置き（左右はsafe area + 16pt、高さは現状どおり）、残りの高さに顔を収める（852×393では約412×190pt）。チップがある場合はその高さも縦配置に含める。チップ・44pt以上の猫ボタン・入力欄が収まらない場合は、入力欄を同じ位置のビューとして下部に保ち、上側だけをスクロールへ切り替える。入力欄を切り替え候補に重複して作らず、カーソルを維持する。エラーや記憶カードの表示・解除でも入力欄を作り直さず、選択範囲と送信後のフォーカス解除を保つ。
- エラー・記憶カード・最大Dynamic Type: 現状の縦スクロール配置を維持する。状態チップはスクロール内容の先頭に置く。

### VoiceOver

- `ConversationAnnouncementPolicy` は変えない。既存の活動状態、首の接続、見ています、エラーなどの通知を維持する。実際の音声・文字返答は speaking → thinking → listening/paused を通るため、speaking → listening を条件にした既存通知では毎回の全文読み上げを保証できない。
- **Claudeの判断（相互レビューで補足）**: 完了・停止後の返答は猫ボタンの「その他のコンテンツ」に「猫の返事」として全文を付け、利用者が必要なときに読み返せるようにする。返答処理中、待機中、空の返答には付けない。通常のフォーカスで全文を重ねて読み上げないよう、importance は default とする。
- これまで状態ラベルが担っていたマイクの状態は、顔ボタンの既存の `accessibilityValue` で伝える。チップには、表示している文言をそのままラベルとして付ける。

## 最初の画面

### 表示するタイミング

- 「会話を始める」を押したら、UserDefaults に完了フラグを保存する。
- 次回以降の起動は会話画面から始め、`beginConversation()` と同じ開始処理（`launchStart()` を含む）を自動で1回だけ行う。マイク権限の確認タイミングは「会話画面で最初に聞き取りを始めるとき」のままで、拒否された場合の回復も既存の処理を使う。フラグを読む UserDefaults は試験で差し替えられるようにする。
- 今回の更新を入れた既存の利用者は、フラグがないので1回だけ表示される。
- 「設定 › このアプリについて › はじめの説明をもう一度見る」から、同じ内容をシートで見直せる。ボタンは「閉じる」にし、会話の開始処理は行わない。

### 配置

- 標準の文字サイズでは2列で、縦スクロールなしで収める（852×393、上下24pt・左78pt・右56pt、列の間隔36pt）。
  - 左列（幅250pt、中央揃え）: 顔（250×115pt、neutral）、見出し「AIの猫と話そう」（28pt bold）、ボタン「会話を始める」（塗りの青、高さ50pt）。
  - 右列: 3項目（16pt、行間1.45、アイコン24pt）と注記（13pt、灰色）。
- アクセシビリティ用の大きい文字では1列にし、縦スクロールを許す。文字を切らないことを優先する。

### 文言（案v1で採用した下書き）

1. （雲）返事は Anthropic の Claude が作ります。送るのは話しかけた文字・会話の要約・覚えたことと、「見て」と頼んだときの静止画像1枚。音声や動画は送りません
2. （iPhone）聞き取り・読み上げ・記憶はこのiPhoneの中。マイクは会話画面を開いている間だけ使います。記憶はいつでも消せます
3. （注意）AIの返事は間違うことがあります。利用料は作者の負担です
- 注記: カメラの許可とこの説明は、あとから「設定」で確認できます

現行の5項目に書かれた事実（送信するもの・しないもの、端末内の処理と保存、記憶の削除、マイクを使う条件、カメラ許可を後から変えられること、誤りと費用）は、すべてこの3項目と注記に含まれている。

## 設定

### 全体

- 会話画面から開くシートであることは変えない。上部の左に「設定」、右に「完了」を置く。校正中は「完了」を無効にし、スワイプで閉じられないようにする（現状どおり）。
- 左列（幅220pt、左safe areaから）: 6つのカテゴリ。アイコン + 文字、高さ44pt。選んでいるカテゴリは背景 `#2C2C2E`。開いたときは「会話」を選ぶ。
- 右列（残りの幅）: 選んだカテゴリの中身を、角丸のグループ（行の高さ46pt）で縦に並べ、右列だけをスクロールする。
- アクセシビリティ用の大きい文字では2列が収まらないので、標準的な一覧から詳細へ進む形にする（Claudeの判断）。

### カテゴリと中身

1. **会話**
   - 声（Supertonic F1）、モデル、考える深さ。注記「声とモデルは次の会話から使います。」
   - 見出し「居眠り」: 眠そうになるまで○分、待機に入るまで○分（ステッパー）。注記「最後に話しかけてからの時間です。待機中はマイク・カメラ・首を止め、猫をタップすると起きます。」反映のタイミングと値の範囲は居眠り機能の設計どおり。
2. **記憶**
   - 覚えていることの一覧（分類 + 文、スワイプで1件ずつ削除）、または「まだ何も覚えていません」「覚えていることを読み込めませんでした」。注記「左にスワイプすると1件ずつ消せます。次の返答から反映します。」
   - 「すべて削除」（赤）と既存の確認ダイアログ。注記「覚えていることと、このiPhoneに保存した会話の要約を消します。元には戻せません。」
3. **カメラと顔追尾**
   - カメラ: アクセス状態。未確認なら「カメラを許可」、拒否・制限なら「iPhoneの設定を開く」（現在の設定画面の処理を移す）。注記「「見て」と頼んだときに、前面カメラの静止画像を1枚Claudeへ送ります。画像は保存しません。」
   - 見出し「顔追尾（首の接続が必要）」: 顔に合わせて首を向ける（トグル）、状態（`FaceTrackingStatus.text`）、左右補正（ステッパー、0〜20°・0.5°刻み、「8.5°に戻す」）。注記「映像はこのiPhone内だけで処理し、保存・送信しません。補正は左側のカメラと画面中央のずれを直します（iPhoneに自動保存）。」
   - 左右補正のスライダーは、狭い右列に収めるため外す（Claudeの判断）。
   - ロボット画面にあった顔追尾の欄と「カメラの許可を設定」ボタンは、ここへ統合する。
4. **ロボット**
   - 接続先: 機器名、状態（`presentation.message`、接続中は緑）、接続操作のボタン（接続を切る／接続をキャンセル／このロボットに接続）。未選択なら「接続先が未選択です」。`calibrationExitWarning` があれば右列の先頭に橙色で出す。
   - 「接続先を変更」→ 既存の接続先選択シート（開くときに検索を始める）。注記「首がつながっていない間も、会話は続けられます。」
   - 動きの強さ（メニュー、未反映の注記は現状どおり）、待機中も少し動く（トグル）。
   - 「中立と回転方向を調整」→ 校正画面へ進む。押せる条件は `canCalibrate` のまま。注記に「ファームウェア・首の状態・指令角」を1〜2行で表示する。
5. **利用量**
   - 1日の上限（ステッパー、10〜2,000回・10刻み）。注記「上限に達した日は、端末内のモデルで短く答えます。」
   - 今日・今月の回数と推定トークン、今月の概算。注記「利用料は作者のワークスペースに課金されます。」
6. **このアプリについて**
   - 見出し「送るもの・保存するもの」: 「返事は Anthropic の Claude で作ります。送るのは話しかけた文字・会話の要約・覚えていることと、「見て」と頼んだときの静止画像1枚です。音声や連続した映像は送りません。聞き取り・読み上げ・顔追尾の映像処理はこのiPhoneの中で行い、会話の記憶もこのiPhoneだけに保存します。」
   - 「はじめの説明をもう一度見る」
   - 見出し「ライセンス」: 現在の「情報」欄にあるライセンスの文。

### 中立と回転方向（校正画面）

「ロボット」から進む画面として残す。2列の右側だけではなく、設定シート全体に重ねて表示する（Claudeの判断）。変えるのは次の2点だけで、ほかは現状どおりにする。

- 「顔追尾の向き」の欄を外す（「カメラと顔追尾」へ移動）。
- 戻るときの確認文から「顔追尾の補正はiPhoneに自動保存されます。」を外す。

- 識別子: 削除する表示の識別子（`conversationCaption`、`robotConnectionStatus`、`memoryNotice` など）に依存する試験は、チップとお知らせの新しい識別子に置き換える。設定の `ConversationSettingsIdentifier` は、移動先の操作部品にそのまま付ける。
- 実機: 会話・look・顔追尾・首・居眠りを併用し、表示と操作を確認する。実施できなかった項目は未実施として記録する。
