# Look Tool Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan natively, task-by-task, with one fresh whole-branch code review at the end. The user explicitly selected look implementation on 2026-10-26. Preserve the established Native method. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 会話中に頼まれたとき、前面カメラの1枚をClaudeへ渡し、同じ返答で見た内容を話せるようにする。

**Architecture:** 既存のFaceCaptureSourceをConversationCameraで共有し、追尾と単発画像の所有権を分ける。LookCoordinatorは既存ターン通知で画像取得・表示・取消を管理し、LookToolはFoundationModelsの画像添付を返す。画像を含んだモデルセッションは返答後に破棄し、文字の記憶だけを引き継ぐ。

**Tech Stack:** Swift 6、iOS 27、SwiftUI/Observation、AVFoundation/CoreImage/ImageIO、FoundationModels、既存ClaudeForFoundationModels 0.2.3、XCTest、ManualRobotClock、Ruby xcodeproj 1.27.0。

**Spec:** `docs/superpowers/specs/2026-10-26-look-design.md`。元要件: `docs/superpowers/specs/2026-10-11-cat-robot-claude-neck-requirements.md` FR-VIS-2/3/4/5・NFR-PRIV-1。独立builder checkは重要な未決事項なし。

- lookはマイク・カメラの許可を勝手に出さない。許可不足は文字の結果にし、通常の会話は継続する。設定からカメラだけ許可できる。

- 静止画像を含むSDKセッションはその返答後に破棄し、次の会話へ画像を再送しない。同じ返答内のツールループでは画像を使用できる。保存する会話記憶は文字だけ。
- 元の顔の形・9プリセットを編集しない。sleep/wake、瞳追尾、後面カメラ、端末内vision、オンボーディング全体の再編は含めない。

- `CameraSnapshotError: Error, Sendable`: permissionRequired / unavailable / busy / timedOut / cancelled.

FaceCaptureSource start/stop represents only the tracking client's demand. Underlying physical generation is private and independently invalidated.
