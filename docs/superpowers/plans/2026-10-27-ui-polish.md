# UI Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. User chose pair programming with Claude.

**Goal:** 聞き取り中チップ、ハード表記、設定と統一した校正画面を実装する。
**Architecture:** 既存のConversationViewStateとチップレイアウトを拡張する。校正の表示だけを分割し、既存RobotCalibrationSessionを共有する。Codexと実際のClaudeでファイルを分担する。
**Tech Stack:** Swift、SwiftUI、UIKit test fixtures、XCTest。
**Spec:** docs/superpowers/specs/2026-10-27-ui-polish-design.md

## Global Constraints
- 基点は1d9e1d0。作業場所は既存feature/ui-reorganizationのb200 worktree。
- 左上チップのsafe area、顔85%枠、入力欄の同一性を保持。
- 校正session・BLE・保存プロトコルを変更しない。
- build/test/gitはCodexが直列実行。実機へ新規インストールや動作指令を出さない。

## Review Focus
- 聞き取りから発話・停止・待機に切り替わった後にチップが残らない。
- 複数チップと文字入力の組合せでもメニュー・入力欄を隠さない。
- 校正カテゴリ移動で値やsessionが初期化されない。
- 大きい文字のカテゴリ詳細でも停止と校正終了に到達できる。
- 接続切れや未保存状態のまま校正を抜ける既存ガードを維持する。
