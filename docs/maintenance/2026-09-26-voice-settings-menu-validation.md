# 声の選択メニュー配置の検証

対象: `feature/voice-settings-menu` / 実装コミット `46d3aa6`。

会話画面の「…」に「声を選ぶ」と「会話を忘れる」を同じ階層で置き、独立した上部の声ボタンを削除した。音声設定は既存の停止処理を通じて開く。記憶機能が未対応の状態でも声の項目は表示する。

- シミュレーター全テスト: 351件成功、実機専用8件スキップ、失敗0。
- 差分レビュー: 指摘なし。
- iPhone 16 Pro / iOS 27.2（USB接続）: `VoiceSettingsIntegrationTests` 4件、`AppCompositionTests` 13件、`ConversationMemoryIntegrationTests` 6件、計23件成功・スキップ0。
- 同じ実機で通常アプリを起動し、Device Hub経由で画面を操作。会話開始後に「…」を開き、「声を選ぶ」「会話を忘れる」が並ぶことを確認。
- 聞き取り中に「声を選ぶ」を押すと会話が停止し、音声設定が開いた。F1からF2に変更し、完了で閉じても会話は一時停止のまま。再度設定を開いてF2の選択保持を確認した。
- 確認後はF1へ戻し、設定を閉じた一時停止状態にした。実際の会話記憶は削除していない。
- 今回の実機UI確認では、アプリのプロセス再起動による声の永続化やマイク認識・音声品質の再比較は行っていない。
