# main履歴の段階的simplify

開始点: `dfc9de1`。作業ブランチ: `feature/main-history-simplify`。

## 方針

ユーザー依頼に基づき、初期構築からmainに入った変更を履歴順に11単位へ分割する。各単位の過去のdiffを固定し、現在のコードに残っている該当実装をReuse / Simplification / Efficiency / Altitudeの4エージェントで読み取り専用レビューする。4件が揃ってから指摘を判定し、挙動を維持する整理だけを適用する。単位ごとに既存の関連テストを実行し、結果を記録してから次へ進む。新機能、バグ修正、実測データの書換え、モデル・プロンプト・音声パラメータの変更は行わない。生成物は生成スクリプト経由で更新する。

## 検証

各単位で関連する既存XCTest、Python unittest、Rubyプロジェクト生成契約テストを選ぶ。最終的に通常schemeの全テストとPython全テスト、Ruby契約テストを実行する。実機専用テストはSimulatorから除外される。実機での音声・推論測定は今回再実施しない。

## 結果


### 1. 基盤・会話ドメイン

4観点レビュー完了。仮認識文を保持するだけで読まれない`provisionalText`を削除。発話時刻と確定文の収集は維持。`confirmPending`の未使用経路は後続の会話統合の範囲で判定する。既存24テストと生成契約テストが成功。開始点の全体検証は350成功・実機専用8スキップ。

### 2. Appleサービス

4観点レビュー完了。エラー変換をファイル内の1関数へ統合、開始中と実行中の同一分岐を統合、出力ゲートで同じ動作だった終了待ち状態を除去、AFMの未読localeを削除、正常終了時の不要な停止Task生成を省略した。ドライバ側の終了処理・末尾イベント・キャンセル順序は維持。キューの一括drain提案は、イベントのロック境界を変更するため今回の整理では見送った。関連92テストと生成契約テストが成功（件数は実行ログ参照）。

### 3. 猫UI

4観点レビュー完了。状態の空文字等を既定値へ集約、文字入力のenum中継を直接アクションへ簡素化、左右反転を既存のCatFaceSide.pointへ統合した。右側の固定図形をキャッシュし、描画用enumerated配列を同一数値IDのindicesへ置換した。4観点は独立エージェントで確認（追加エージェント上限のため2名は完了済みエージェントを再利用）。見送りなし。関連54テストと生成契約テストが成功。

### 4. アプリ統合とライフサイクル

4観点レビュー完了。到達しないconfirmPending経路を削除。計測中の指標をhandlesだけで管理し、文字入力の復旧表示と計測キャンセルの重複を既存処理へ統合した。発話区切りまでの待ち時間はUtteranceSegmenterの既存時刻・設定から計算し、ViewModelの二重の開始時刻を削除した。停止や権限の所有権判定は維持。見送りなし。関連113テストと生成契約テストが成功。
