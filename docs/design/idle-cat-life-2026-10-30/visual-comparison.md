# あくび（yawn）のベクター化と参考画像との比較

参考: `yawn-reference.png`（1672×941、16:9 の全面がキャンバス。目尻の線なしの最終版。生成プロンプトは `yawn-reference.prompt.txt`）。
実装: `CatFaceAppearance.yawn`（0 通常 → 1 峰）、`CatFaceAppearance.yawning`（sleepy + 両目を閉じる + yawn 1）、`Eye.blink`（片目ずつのまばたき）。
既存 9 表情は yawn 0 のままで、描画は変えない（下の baseline 比較）。

## 計測と当てはめ（`trace_yawn.py`）

`/usr/bin/python3 trace_yawn.py yawn-reference.png [raster.png]`。画素を代表色（黒・金・クリーム・珊瑚・暗赤・桃・白）に最近傍で分類し、

- 閉じた目の弧（金）: 左右の弧の列ごとの上縁・下縁を neutral の目の枠（中心 (0.2374, 0.4327)、半径 (0.1247, 0.2231)）の
  局所座標 (u 鼻側が正, v 下が正) に写して左右を平均し、頂点で水平に接する 3 次ベジェ 2 本ずつ（上縁・下縁）を最小二乗で当てはめる。
  先端 外 (−0.515, −0.064) / 鼻側 (1.106, 0.098)、頂点 u 0.056（上縁 v −0.358、下縁 −0.170、太さ 0.188 = キャンバス高さの 0.042）。
  残差 rms 0.5〜1.6 px @941。
- 口の輪郭（クリーム）: 外縁を輪郭追跡し、線幅（実測 0.018〜0.019、製品の `mouthLineWidth` 0.0185 と同じ）の半分だけ内側へ
  ずらした中心線を、x/y の極値（水平・垂直に接する）で区切って実寸で当てはめ、残差 1.6 px 超の区間は接線を共有して二分する。
  上中央は尖り（自由な接線。鼻の下に隠れる先頭 16 点は使わない）。左半分 9 本、右は鏡映。区間ごとの rms ≤ 1.5 px @941。
- 牙: 上唇のくぼみの底（x 0.424〜0.456）の内側の縁より下のクリーム色。左右の縁を根元（唇の中心線の高さへ外挿）→ 先端の
  3 次ベジェで当てはめ（rms ≤ 0.7 px）。先端 (0.4405, 0.6281)。
- 舌（珊瑚＋桃の最大成分）: 上縁の弧を、輪郭の中心線上の接点 (0.3876, 0.8034) → 中央で水平な頂点 (0.5, 0.7024) の
  3 次ベジェで当てはめ（rms 1.8 px）。下は長方形で閉じ、描くときは輪郭の内側で切り抜く。
- 鼻: 上端 0.4315、下端 0.5154、幅 0.0754 → 製品の鼻（0.6163 / 0.7045 / 0.0796）を下端基準に −0.1891 動かし 0.95 倍。
- ひげ: round 1 は製品の中心線を平行移動 −0.190（3 本の当てはめ −0.195 / −0.189 / −0.187）＋ 根元回り −1.7°（sleepy の −7° に加える）。
  round 2 は参考の 3 本そのものを当てはめる（左右を平均した中心線の 3 次ベジェ、rms ≤ 1 px、中央の太さ 0.0132 / 0.0131 / 0.0157）。
  round 3 までのひげの計測は誤り: ひげの端の画素は白に分類される（例: 左下の根元 (438, 562) は RGB 255,250,234）のに、
  mask がクリームだけだったので端が欠け、「短い」「左右で長さが違う」と測っていた（root の目視で発見）。round 4 で
  mask をクリーム｜白にして測り直すと、長さは通常のひげとほぼ同じ（根元 → 先端 0.204 / 0.202 / 0.156 vs 製品 0.198 / 0.202 / 0.158）、
  左右の外接は 0.001 以内で一致。左右を平均した中心線を当てはめる（rms ≤ 0.5 px、中央の太さ 0.0149 / 0.0149 / 0.0169）。
- 色（縁を除いた内側の中央値）: 金 #FEC83F、クリーム #FBEED9、暗赤 #3E1514、舌 #EE7669、鼻 #F67D69。製品は既存の
  `Palette`（閉じた目の弧 #FDCA43、クリーム #F9E9CB、口の内側 #3A1A1E、鼻 #FB8B6D）をそのまま使い、舌だけ #EE7669 を足した。

当てはめた形を同じ大きさに描いた照合（Python、参考の分類との IoU）: 金の弧 0.945、口の輪郭＋牙 0.870、口の内側 0.954、舌 0.971。

## 実装の要点

- `CatFaceGeometry.closedLid(frame:yawn:)`: sleeping の ∪ と あくびの ∩ の 12 点を線形補間（0 と 1 の間はほぼ平らな線）。
- `nose(yawn:)`: 下端基準の相似縮小 ＋ 平行移動。`whiskers`: yawn > 0 のときだけ峰の形（`yawnWhiskerSpecs`。根元・制御点・
  先端・太さ）へ線形補間（左右対称）。
- `mouth(...)`: ω・丸い口は鼻と一緒に上へ動かしつつ `yawnBlend = min(1, yawn / 0.35)` で消し、峰の口（輪郭・舌・牙）を
  鼻の下端に吊るして yawn 倍の大きさで描く（基準点 `yawnMouthAnchor` = 鼻の下端 + 線幅/2 を中心に相似。線幅は変えない）。
  上中央の尖りとその制御点だけ `yawnMouthCuspRise` 0.0042 上げ、線の外縁が参考どおり鼻の下端より上（0.5112）へ届く
  （鼻を後から描くので鼻の先が尖りに埋まる）。口のほかの部分は動かさない。
- `CatFaceRenderer`: 暗い内側 → 舌（内側で切り抜き）→ 牙 → クリームの輪郭線を 1 枚の層にまとめ `yawnBlend` の透明度で重ねる。
- 検査（`CatFaceGeometryTests` と `scripts/render_face.sh check` で同じ判定）: 既存表情は yawn 0・片目まばたき 0 であくびの部品を持たない、
  yawning は両目をまぶたで覆い ∩ の弧（横幅 0.202 ± 0.01、頂点の厚さ 0.042 ± 0.004、両端は尖る）、口の外接 0.249×0.40、
  口の上端 0.5112 ± 0.003、鼻の下端 0.5154、舌の上端 0.7024 ± 0.003、牙の先端 0.628 ± 0.003 で左右対称、ひげは参考の
  外接 ± 0.005、yawn 0→1 で口の高さが単調に増える、yawning でも要素間の交差なし（線幅 1 と 1.35）。

- 色分類の IoU（参考を 1280×720 に縮小）: 全体 金 0.941、クリーム 0.769、珊瑚＋桃 0.978、暗赤 0.879。
  口の領域: クリーム 0.877、珊瑚 0.981、暗赤 0.949。ひげの領域のクリーム 0.661（長さの差。下記）。
- 外接の差（描画 − 参考、px @1280×720）: 閉じた目の弧 左 x +0.8/−2.5 y −0.8/−3.8、右 x +1.8/−2.3 y +0.7/−2.2
  （左右を平均した形なので参考の左右差 2〜4 px が残る）。口の輪郭 x ±1.2 y +3.0/−1.3、牙 ≤ 2 px、舌 x ±3 y ≤ 0.5、鼻 ≤ 2 px。
- 口の内側の上端が 8.8 px 下（0.5361 vs 0.5239）: 参考は鼻の先が唇の尖りに 4 px 食い込み、尖りの直下で唇が薄い（約 0.012）。

- ひげ: 列ごとの中心 y の差 平均 +3.2 / −0.2 / −1.6 px（左）、+3.4 / +0.4 / −1.0（右）。外接は「参考が上から 7% / 5% / 22%

- 参考の質感で合わせないもの: 舌の上側の明るい帯（2 色）、唇の尖りの下の薄さ、金の弧の縁のにじみ。色は既存 Palette を優先。

## 補間の途中（`canvas-yawn-from-neutral-50.png`、neutral → yawning の AnimationVector 線形補間 0.5）

- 目が開いたまま yawn だけ上がると、上がるひげが目の外形（下端 0.656）に触れ始める yawn は happy 0.18、
  neutral / curious / thinking / speaking 0.22、sleepy / surprised / sorry 0.25（各表情 → 峰の線形補間を 0.01 刻みで、
  ひげと外形全体の交差で判定）。峰では目を閉じているので問題ない。root 側の `CatFaceAppearance.eye(side)` が yawn > 0 で
  まぶたを早く閉じ切る（yawn 0.15 まで）ので、keyframe や割り込みの補間でも開いた虹彩にひげが重ならない（root の Life テスト）。
- 閉じた目の弧は yawn 0.5 でほぼ平らな線（∪ と ∩ の中間）。0.25 秒程度の遷移なら目立たない。
- 注意: CoreGraphics の `outline.subtracting(lid)` は、まぶた 0.15 以上でほぼ空（要素はあるが外接が null）を返したので、
  「見えている虹彩」との交差判定には使えない。ここでは外形全体との交差で判定した。
