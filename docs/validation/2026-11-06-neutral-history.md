# issue #23: 中立発話と聞き返しの会話履歴

中立と判定した元の発話と「今の、ぼくに言った？」の読み上げが正常完了した往復を、既存の記憶サービスへ記録する。次の「言ったよ」が返答生成へ進んだ場合、元の話題と聞き返しを新セッションのinstructionsへ渡す。固定の聞き返し自体はLLM生成や利用回数の加算をしない。宛先判定・15秒・肯定/否定の振り分け、schema、モデル、Smart Turn、エフォート設定は変更していない。[設計](../superpowers/specs/2026-11-06-neutral-history-design.md)を参照。

## simplify・独立レビュー・相互受け止め

agmsgのClaudeが実際の `/simplify` を呼び出し、再利用・簡素化・効率・変更箇所の深さの4担当を並行で実行した。Codexは `superpowers:requesting-code-review` の独立サブエージェントへ同じ固定差分を渡した。両方の初回報告が保存されるまで相手の報告を読まず、その後、双方が `superpowers:receiving-code-review` で実コード・証跡を照合した。Codex本体が単一writerとして採否を確定し、修正後は双方が差分を再確認した。

独立レビューは初回に指摘なしとしたが、相互確認でREADMEの古い「宛先判定に使った発話は保存しない」を見落としていたと訂正した。ClaudeのImportant C1を採用して、READMEの記憶/送信データと、既存要件のFR-MEM-7/NFR-PRIV-1にissue23の保存条件を明記した。双方の最終確認では未解消のCritical/Important/Minorはない。

保存試行を待つ時間は聞き取り再開までの時間と既存15秒窓に含まれる。次応答の文脈はメモリ内appendで得られ、保存のawaitは永続化の試行を終える順序点であり、成功保証ではない。失敗は未保存表示・メモリ内保持・再試行で扱う。セッション無効化と次回再構築は確認済みだが、実時間とリモートのキャッシュ費用/ヒット率は未計測。12k文字は圧縮トリガーであり、snapshotの上限とは記さない。

正常完了した往復は否定・期限切れ後も残り、後の要約に話題が残る可能性がある。種類タグ・巻き戻しは追加しない。「言ったよ」は肯定語一覧へ追加していないため、分類器が返答へ振り分ける条件は従来どおり。固定fixtureは実モデルの意味解釈を保証しない。端末内fallbackの履歴消費の再設計、既に統合したSmartTurn/issue25の再レビューは対象外とし、全体回帰テストでは継続して検証する。

初回・相互・最終報告とxcresult/ログは `/tmp/cat-issue23-neutral-history-20261106/` に保持する。通常アプリは独立したDerivedDataを使用した。実機転送は一度無線接続リセットで失敗した後、ユーザーの接続・解除連絡後に再試行して成功した。会話内容の実機受入は未実施。統合版の通常ビルド・更新の証跡も同ディレクトリの `main-normal/` に保存する。
