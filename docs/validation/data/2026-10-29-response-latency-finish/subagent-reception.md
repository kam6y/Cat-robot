## Claude's explicit rejected/deferred suggestions

- **Confirmed normalization reuse (E2): reject.** Current code deliberately normalizes confirmed text again and validates pre-trim limits; injected normalization has no purity contract. Matching originals do not justify skipping validation.
- **Debounce nonisolation or joining after send (E3): reject for this change.** It alters scheduling/ownership and may allow stale preparation admission. There is no measured need.
- **Unify all 2,000-character limits: defer.** Limits cover different stages and precede this feature. Retain the new speaker validation on reuse.
- **Test-factory consolidation: defer.** It does not improve the behavioral evidence relevant to this task.
- **Move denoise cancellation checks out of the vendor loop: reject.** Wrapper checks cannot interrupt a synchronous native sequence between steps.
- **Move 16-character guard before normalization or into the parser: reject.** Latin correction can alter length; only the speaker has the validated normalized input. Keep the 75ms ownership in playback.
- **Expose candidates to old next() consumers: reject.** Existing `next()` correctly filters hints and preserves committed-sentence callers.
- **Style caching: defer.** It is outside the selected implementation and not supported as the measured bottleneck.

## Root scope and completion conditions

The suggested bounded scope is technically justified. If CS2 is included, use the simple tracing function without new tasks or tool wrappers, and retain normal cancellation checks, actor hops, and return/error behavior in the bodies. Keep explicit candidate-task and stability-task drain paths. Compile/test only the affected behavior through the normal executor workflow; this reception is not test certification.

The fresh review's timer-reset Minor can be deferred transparently: current mismatch tests revise after preparation begins, while the missing trigger is revision before the first 75ms expires. Named delay constants and a derived negative-test wait improve resilience but do not close that distinct gap.

The added kanji-boundary and mixed delayed-hit fixtures address the right workload gap. Their presence and the root-reported 863-test baseline do not establish the physical latency gate. Before merge, require the current paired physical result, current-model smoke, preserved normalization/native provenance, and evidence that clearly separates old all-kana history from current kanji-preserving acceptance.
