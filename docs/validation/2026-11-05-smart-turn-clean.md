# Smart Turn単体への整理（2026-11-05開始、2026-11-06完了）

通常アプリをiPhoneへインストール・起動済み（PID 6812）。Smart Turnは通常構成でON。

割り込み前の6ddf6baからfeature/smart-turn-cleanを作り、Smart Turnだけを追加した。旧構成はexperiment/smart-turn-audio-onlyの0249e34に保存。mainの変更、merge、pushは行っていない。

## 最終動作

- 元からあるASRの固定1.2秒無音終了と最大発話時間を主経路として維持。ユーザーが2026-11-06に明示確認した構成。
- Smart Turn v3.2 + Silero VADを通常録音に必須で接続し、終了確率が厳密に0.5を超えれば早めに認識を閉じる。16発話フレーム以上、7無音フレーム（224 ms）、300 msの有効期間。
- 後から追加された3秒の音声タイムアウト、3秒ASR上書き、100 msでモデル準備を打ち切る処理は削除。
- モデル準備は成功またはエラーまで待つ。初期化・変換・VAD・推論・入力キューの実エラーは「発話の終了判定に失敗しました」と表示して停止する。準備中の停止操作は同期モデル処理を待たない。
- モデルの有効な未完了判定や古い結果はエラーとして扱わない。通常のASR終了は引き続き動作する。
- 音声終了には認識中の文字・数字の活動を要求。確定済み前半とstop時のfinal末尾を一度だけ連結する。
- 返答中は録音しない。語尾ルール、適応タイマー、Foundation Models終了判定、共有AEC音声エンジン、割り込み後の発話履歴調整、比較実験用harnessは含まない。

## 確認の限界と判断

旧測定は共有AEC入力、今回の構成は土台の入力エンジンを使う。旧データから今回の人の発話精度、雑音耐性、実機応答時間を推定しない。固定モデルのピン留め・ロード・数値契約は確認しているが、広い音響評価は今回の整理の範囲外。

文字活動前のモデル判定は破棄するため、認識の出方によって早期終了を使えない場合がある。同期する第三者モデル処理自体を強制停止せず、所有側をキャンセルして待たずに戻る。バックグラウンド処理中の再準備はbusyをエラーとして返し、代替処理へ逃がさない。

当初のASR3秒維持案と、その後のASR終了を無効にする案は、ユーザーの確認で撤回した。最終構成は元のASR1.2秒主経路を維持する。その他の後続機能はrollback指示どおり戻していない。

レビューで判断を留保した項目、理由、誤りだった場合の影響は、完了時のexecution-ledger.mdに全件保存する。Minorの積み残しはない。
