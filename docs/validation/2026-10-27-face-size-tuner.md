# iPhone用の顔サイズ調整アプリ

2026-10-27。ユーザーの依頼で、顔の大きさを自分で決めるための別アプリ「顔サイズ調整」を作成し、iPhone 16 Proへインストール・起動した。製品コードは `be3d780`、最終試験の画像取得補助は `c2e2c4b`。

## 使い方

1. iPhoneの「顔サイズ調整」を開く。
2. 下のスライダーまたは「−」「＋」で大きさを調整する。50〜100%、0.5%刻み。初期値とリセットは調整前の本体と同じ85%。
3. 表情を選んで比較する。操作を隠すには「全画面」、戻るには右上の調整ボタン。
4. 「値をコピー」を押してCodexとの会話に貼り付ける。表示された割合を伝えるだけでもよい。

倍率は別アプリ内に保存される。本体への自動反映は実装していない。ユーザーが選んだ値を受け取ってから、Codexが本体へ反映する。[ツールREADME](../../tools/face-size-tuner/README.md)。

## 実装と検証

本体の顔の描画3ファイルを直接参照し、通常会話画面と同じsafe area・位置・倍率の計算を使う。顔の縦横比、各パーツの形、10種類の表情は既存の描画に従う。表示値、描画、保存、コピーには同じ正規化済み倍率を使う。

- 別アプリの全試験 **5件成功、スキップ0、失敗0**。
- 保存と復元、リセット、不正な保存値、0.5%刻みへの丸め、コピーした小数との一致を検証した。
- 10表情それぞれで、85%から68%へ変えると描画の縦横が同じ0.8倍になることと、中心を保つことを画素から検証した。
- 実際のSwiftUI画面でスライダー、増減、コピー、リセット、全画面への切替と復帰を操作した。標準文字と最大アクセシビリティ文字サイズで操作に到達できることを確認した。
- 最初の4試験は未実装の状態で44箇所の失敗を確認した後に実装した。最終試験はiPhone 18 Pro / iOS 27.0 Simulatorで実行した。
- 本体アプリのソース・試験・プロジェクト等223入力は、直前に成功した839件の試験対象から変えていない。本体の顔サイズは85%のまま。

## 実機への配布と次の操作

署名検証後、`com.kamby.CatFaceSizeTuner` としてiPhone 16 Proへインストールし、起動成功を確認した。本体 `com.kamby.CatRobot` のインストール情報は前後で一致した。本体の再インストール、データ変更、ハード指令、ファームウェア変更は行っていない。[配布記録](face-size-tuner-2026-10-27/device-deployment.json)。

対象は通常会話画面の静止した顔。文字入力・設定の顔サイズや発話・まばたきの挙動はこのツールの対象外。引き渡し後にユーザーが80%を選び、下記のとおり本体へ反映した。[実行記録と判断](face-size-tuner-2026-10-27/execution-ledger.md)。

## 選択した80%を本体へ反映

ユーザーの「80%にしよう」を受けて、通常会話画面の枠を85%から80%（`ConversationView.faceScale = 0.80`）へ変更した。中心位置・縦横比の計算はそのまま。製品変更はこの倍率と説明コメントのみで、コードのコミットは `7ac5bea`。

既存の `FaceConversationPresentationTests` **15件成功、スキップ0、失敗0**。80%の期待値は製品定数から独立させ、左右のsafe areaでの顔の中央配置、枠への収まり、チップとの配置を確認した。[試験概要](face-size-tuner-2026-10-27/main-app-80-test-summary.json)・[Simulator画像](face-size-tuner-2026-10-27/images/main-app-80.png)。本体223入力のうち、直前の全体試験から変わったのは会話画面とその既存試験の2ファイルのみ。今回、全体839件は再実行していない。[今回のソースハッシュ](face-size-tuner-2026-10-27/main-app-80-source.json)。

署名付きビルドと署名検証に成功し、iPhone 16 Proへ更新インストールした。インストール結果と更新後のアプリURLが一致することを確認した。実機でのアプリ起動・画面の目視確認は行っていない。[反映・配布記録](face-size-tuner-2026-10-27/main-app-80-verification.json)。
